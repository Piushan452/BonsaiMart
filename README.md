# 🌱 BonsaiMart - Online Bonsai Shopping App

An Android e-commerce application for buying bonsai plants online. Built with Java and Firebase.

---

## 📱 Features

### Core Features
- 🔐 **Firebase Authentication** - Login/Signup with email verification
- 🛒 **Shopping Cart** with SQLite offline support
- 💳 **PayHere Payment Integration** - Secure checkout
- 📦 **Order Management** - Track orders with delivery dates
- 🔔 **Notifications** - Real-time updates from admin

### Advanced Features
- 🗺️ **Google Maps** - Store locations with directions
- 🌤️ **Weather Widget** - Live Kandy weather (OpenWeather API)
- 📱 **Shake to Add** - Shake phone to add products to cart (Sensor)
- 👆 **Gestures** - Long press, swipe, double tap on cart
- 🌐 **Offline Mode** - Network detection with Broadcast Receiver
- ⚙️ **Persistent Data** - SharedPreferences + Internal Storage
- 📊 **JSON Serialization** - Gson library
- 📡 **Wi-Fi Info** - Network status display
- 🔍 **Search History** - Recent searches saved

| Technology | Purpose |
